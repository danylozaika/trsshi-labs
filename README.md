# РОЗРОБЛЕННЯ RAG-СИСТЕМИ

Ця система може бути корисною роботодавцям, які бажають знайти роботи конкретних людей, за конкретний час, за конкретною темою. 

## Встановлення необхідного стеку
### Встановлення Chroma
Бібліотеку для chroma можна встановити командою:
```
pip install chromadb
```
### Встановлення Mistral
Мовну модель можна встановити через **ollama** командою:
```
ollama run mistral
```
### Встановлення ембедінг моделі
Ембедінг модель можна встановити через **ollama** командою:
```
ollama pull all-minilm
```
